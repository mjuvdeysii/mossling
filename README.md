## 这是什么

摸索台灯不是育儿课。它不教大人怎么养孩子，也不给孩子打分，只陪大人和孩子一起玩、一起长大，并把长大的样子记下来。

| 名字 | 属于谁 | 含义 |
|---|---|---|
| 摸索 | 孩子 | 0–3 岁的孩子用手、用嘴、用眼睛摸索世界。Moss 的名字取自「摸索」，头上的新芽一直在长。 |
| 台灯 | 大人 | 台灯不替人走路，只把桌面照亮。Otto 头顶的金色灯珠就是这盏灯。 |

在这里做三件事：

| | 在哪里 | 不做什么 |
|---|---|---|
| **一起玩** | **今天一起玩**：每天推荐一个这个月适合的活动，第 1 步的插画一眼可见，点开就是一步步的图文、准备什么、什么时候停下；这周另有两三个备选活动，每周自动轮换 | 不布置任务，不设打卡 |
| **看他长大** | 0–36 个月，一个月一站，共 37 站；蒙氏串珠链成长地图、成长册、WHO 生长曲线、接种与儿保 | 不比较，不做发育诊断 |
| **记下来**（可选） | 亲喂、瓶喂、睡眠、尿布、辅食、体温、第一次等一点即记，计时显示在锁屏与灵动岛上；亲喂分侧时长、瓶喂奶量、睡眠统计 | 不上传，不需要账号 |

满 36 个月是最后一站，却不是终点：**故事仍在继续。**

## Moss 与 Otto

两位伙伴不说话，只用眼神和动作陪伴。Moss（摸索）是孩子的好奇心：苔绿色软石，两只眼睛，头顶一片薄荷芽，什么都想先摸一下。Otto（台灯）是大人的陪伴：深蓝色，一只大眼睛，头顶一颗金色灯珠，专注又耐心，Moss 摸到哪里，他就把灯往哪里偏一点。家长可以选任意一位作为主伙伴，两位功能完全相同。完整设定见 [docs/IP.md](docs/IP.md)。

**隐私与合规**：完全离线、不联网、不需要账号，不含广告、统计或第三方 SDK；首次打开提供同等权重的「同意 / 不同意」确认卡（不同意仍可浏览全部育儿内容），支持应用内撤回同意、面容 ID 应用锁、iOS 数据保护与本地 JSON/CSV/Markdown 导出。CI 在模拟器测试中持续采集应用进程网络日志（`ios_network.txt`）核查零联网。

**开发**：`ios/project.yml`（XcodeGen）；CI [`.github/workflows/ios.yml`](.github/workflows/ios.yml) 运行单元测试、截图测试（含 6.9 英寸 App Store 截图产物）、无障碍审查与滚动性能测试，并在合入 `main` 时自动上传 TestFlight。设计说明见 [ios/DESIGN.md](ios/DESIGN.md)，合规对照表见 [ios/COMPLIANCE.md](ios/COMPLIANCE.md)，路线图见 [ios/ROADMAP.md](ios/ROADMAP.md)。

## 内容依据

育儿内容整理自世界卫生组织、联合国儿童基金会、国家卫生健康委员会、国家疾病预防控制局、中华预防医学会、美国疾病控制与预防中心、美国儿科学会等机构公开发布的指南与资料，在应用内「内容来源」中逐项标明机构、文件名称、发布日期与核对日期。`app/src/main/assets/content.json` 为两个平台共用的内容；`who_growth.json` 由 `tools/export_who.py` 生成；iOS 插画由 `tools/picturebook.py` 生成，安卓插画由 `tools/illustrate.py` 生成。

## 制作

摸索台灯由创作者本人构思与主导，借助 AI（Anthropic 的 Claude）辅助完成产品设计、插画与代码。
