### 2. 中国大陆上架（需要你决定）

- 工信部要求在中国大陆分发的应用办理 **App 备案**，App Store Connect 的「ICP 备案号」栏要填备案号；只能由中国大陆注册的主体办理，审核约 20 个工作日。
- 完全离线、不联网的应用可能被认定为无需备案；本应用不联网，但是否适用需向备案服务商或 Apple 确认。
- 可选路径：① 由你的中国主体办理备案后上架中国大陆；② 先在中国大陆以外的店面上架；③ 向 Apple 或服务商确认离线豁免。

### 3. TestFlight 公开测试（外部测试员）

- 首个外部构建需通过 Beta App Review。必填「Beta 版 App 描述」，建议同时填反馈邮箱。
- 建议描述（可直接粘贴）：
  > 摸索台灯陪大人和 0–3 岁的孩子一起玩、一起长大（孩子摸索，大人点灯）：每周从架子上挑几件教具，照着逐步插画和孩子一起玩；可选的照护记录支持喂奶、睡眠、尿布计时与补记。本版请重点测试：首页本周架子与成长滚轮、活动页的插画是否看得懂、喂奶计时的暂停与换边。应用不需要账号，不联网。
- 「测试内容」可每版更新为本版新增的互动与修复。

### 4. 产品页（编辑评选的一部分）

- 截图：6.9 英寸 iPhone 必备；建议 5 张：本周架子、活动逐步插画、成长滚轮、记录时间线、Moss 与 Otto。
- App 预览视频（可选，强烈建议）：前 3 秒展示转动成长滚轮、宝宝长大。
- 宣传文本与描述：中文为主；如计划其他店面，同步本地化。

### 5. 编辑精选提名

- 在 App Store Connect「推荐提名」(Featuring Nominations) 提交 1.0 上线；Apple 要求至少提前两周，希望更广泛考虑时最多可提前三个月。
- Apple 对编辑精选的说明：「在设计上无可挑剔，并提供创新、愉快的体验」；考量包括用户体验、界面设计、创新、独特性、无障碍、本地化与产品页。

## 三、对照编辑评选考量的差距

| 考量 | 现状 | 差距与建议 |
|---|---|---|
| 界面设计 | 绘本插画、IP、贴纸图标、纸面界面 | 继续打磨；需要真实家长测试 |
| 创新 | 实时活动、灵动岛、小组件、成长滚轮 | 可加 App Intents（快捷指令 / Siri 记一次喂奶）、交互式小组件 |
| 独特性 | 蒙氏教具架 + 逐步绘本 + 双 IP | 已具备 |
| 无障碍 | 动态字体、VoiceOver、减弱动态、对比度 AA | 填写无障碍营养标签；做一次完整 VoiceOver 走查 |
| 本地化 | 仅简体中文 | 若目标是中国区育儿板块，简体中文足够；若面向更多地区，需繁体中文与英文 |
| 产品页 | 未准备 | 截图、预览视频、描述 |
| 评分与评价 | 未上架 | 公测收集反馈后再上架 |
