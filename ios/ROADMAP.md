# 芽芽月历 iOS 版 · 重构路线图

目标：一个原汁原味的 iOS 应用，而不是安卓版的搬运。内容与安卓版一致（content.json、WHO 数据、条款），其余按 Apple Human Interface Guidelines 与最新 iOS 设计语言（液态玻璃 / Liquid Glass）重新构思：界面、配色、字体、插画、Moss 与 Otto、应用图标。

## 原则
- 以 developer.apple.com 的 Human Interface Guidelines、Liquid Glass 设计与示例代码为准；采用系统控件、系统材质（glassEffect、GlassEffectContainer）、SF Symbols、系统字体与动态字体。
- 不再沿用安卓版的 Material 风格、Young Serif / Noto Serif 字体与 Material 形状。
- 蒙台梭利教具的形象（串珠、数棒、圆柱插座、粉红塔、摇铃等）用 SF Symbols 式的线面图形与液态玻璃材质表达，参考 Apple 官方图标与示例中模拟实物的做法。
- 不出现需要横向滑动才能看全的内容；放不下就换行，先判断是否需要展示。
- 正式、第三人称；说明性文字只留给早教内容本身。
- 喂奶不得用红色水滴（像血滴）。
- 安卓版不在本路线图内；需要同步的改动单独列出。

## 状态
- [x] 1. 可运行的第一版、TestFlight 流水线（CI 无签名归档、导出时云端签名）。
- [x] 2. 整体构思：一本大人和孩子一起翻的绘本 + 一盒教具 + 两位伙伴。四个标签「今天 / 地图 / 手帐 / 我的」，标签栏不折叠，搜索在右上角；内容从大标题下方开始，不被导航栏遮挡；卡片缩放进入、往回滑或下拖缩回，列表行推入，临时任务从底部弹出；计时显示在标签栏上方附件区。
- [x] 3. 统一的立体质感：图标块、卡片、伙伴、珠子、场景、插画共用一套光影（左上来光、柔和渐变、细高光、柔和投影）；暖彩虹 + 玻璃糖果色（玻璃粉、薄荷、蜜桃）；每个标签一种底色光晕（今天蜜桃、地图薄荷、手帐玻璃粉、我的丁香紫）；系统圆体字。
- [x] 4. 今天：天空场景卡（随时间变化）与月龄、今天的教具卡（「做过了」一键计数）、木架子（本周教具，整理从底部弹出）、下一次接种与儿保。
- [x] 5. 活动：直接浏览图文步骤，底部一个按钮，每做一次记一次（记入手帐「一起玩」，与安卓通用），以金珠显示次数与上次日期；撤销在长按菜单。
- [x] 6. 成长地图：小路穿过草地、森林小丘、小河村庄，每月一颗立体珠子与路牌，伙伴站在宝宝那一站，36 个月后路继续延伸。
- [x] 7. 月份：封面、要点、教具卡（显示次数）、「这个月」图标格（带进度环），各部分单独成页。
- [x] 8. 手帐：贴纸板快捷记录、日历式一周、方格纸日页（大日期、三枚印章式总计、时间条、固定列宽的记录）。
- [x] 9. Moss 与 Otto：恢复安卓版的轮廓与神态，柔和立体光影；图标为两位伙伴（Otto 把金珠垂到 Moss 头顶）。
- [x] 10. 插画第二版：146 幅步骤图与 37 张封面按暖色柔光重画，封面里有两位伙伴。
- [ ] 11. 插画第三版：人物与教具更精致（表情动作、教具细节），步骤之间更有变化。
- [ ] 12. 小组件与实时活动按新视觉重做；「我的」里的成长册。
- [ ] 13. 辅助功能：旁白、最大号动态字体、减弱透明度与动态效果的检查。
- [ ] 14. 商店素材与发布。

## 待用户处理
- 开发者账号中创建 App Group `group.app.mossling`，并在 App ID `app.mossling`、`app.mossling.widget` 上启用；完成后在仓库 Settings › Variables 添加 `APP_GROUP=1`，小组件即可读取手帐数据。
