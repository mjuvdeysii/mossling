# 更新日志

## 1.3.2
这是一次面向日常陪伴的全面升级：带来床头暖光夜灯与助眠声景、24 小时昼夜节律盘、可翻页的成长绘本，以及完整中英双语和更顺手的小组件。

- **Otto 床头夜灯与实时助眠声景**：在首页、记录页、计时页或桌面「床头台灯」小组件随时点亮全屏暖光夜灯——上下滑动即可带机械顿挫手感地无级调光，倾斜手机暖光随惯性微晃；内置「雨落纸窗」「草坡微风」「温暖心跳」「木琴摇篮」四种离线实时合成声景，支持锁屏后台播放与 15/30/60 分钟渐弱停止，并可直接在暗光下开始或记录睡眠与亲喂。
- **24 小时昼夜节律盘**：在「记录 › 昼夜节律」里用 7 天 / 14 天同心圆盘直观呈现宝宝自己的日夜节律（12:00 正午在上、00:00 午夜在下、外圈为今天）；手指滑过表盘即可用暖光束逐小时查看睡眠与喂养事实，并支持一键生成高清节律印画留存分享。
- **成长绘本与第一次纪念照片**：成长册新增横向翻页「成长绘本」模式，从出生那一页起一页页翻看插画、第一次瞬间、玩过的托盘与手记，底部配有会随翻页移动的蒙氏串珠轨迹并支持单页留存；记「第一次」时可选留一张仅存本机的纪念照片（无需相册权限），以拍立得相纸收进时间线与绘本里。
- **轻柔手感音效**：为成长地图踩石、活动串珠步进、节律盘拨动、翻页与轻戳 Moss/Otto 加入精细的 CoreHaptics 与木珠轻响（夜灯、睡眠计时及静音模式下自动完全静音，可在「我的」中随时开关）。
- **完整英文体验与桌面小组件焕新**：整个应用现已支持中英双语自由切换；新增「一键记录」「床头台灯」「成长故事窗」小组件与控制中心/Siri 免手记录，支持桌面换活动回流、尿布撤销与点击直达；同时大幅优化 3D 软胶材质渲染性能与页面过渡动效。

## 1.0.1
更稳妥的本地记录，更顺手的生长曲线，以及多处夜灯与手感打磨。

- **夜灯与手感细节**：夜灯模式下的软胶卡片、计时页与成长册相纸色调更统一；首页「换一个」加入轻柔的换卡过渡，活动页新增串珠步进条，背景飘落画面在后台自动暂停更省电。
- **WHO 生长曲线升级**：曲线更顺滑，可在「当前阶段」和「0–36 个月」之间切换视野，点击曲线下方即可逐条查看每次测量与较上次的变化，并直接编辑。
- **更安心的本地存储**：加固记录与小组件之间的数据同步，避免意外覆盖历史记录；强化应用锁保护，并优化锁屏实时活动的显示。
- **记录与导出修正**：表格导出与编辑页里的时长现在会准确扣除暂停时间，只记录身长或头围时也能正常显示。
- **稳定性修复**：修复计时刚满 1 分钟内选择结束时间，以及导入异常日期或测量值时可能闪退的问题。

## 1.0.0
摸索台灯的第一个 iOS 版本，陪你和 0–3 岁的孩子一起玩、一起长大。

- **孩子摸索，大人点灯**：首次打开时，Otto 的灯亮起，Moss 在灯下摸索；在「关于摸索台灯」里可以读到名字的故事。
- **今天一起玩**：首页每天推荐一个适合当前月龄的活动，第一步插图一眼可见，随时可以「换一个」；每周自动准备几项备选。
- **37 站成长与 46 个家庭活动**：涵盖 0–36 个月共 37 站指南、46 个家庭活动与 146 幅逐步插画，支持按六个发展领域、专题与搜索浏览。
- **可选的照护记录**：支持喂养、睡眠、尿布等记录与计时，可补记时间、分别记录暂停与换边，并提供时间线、统计、WHO 生长曲线、锁屏实时活动与桌面小组件。
- **安静陪伴的 Moss 与 Otto**：两位伙伴不说话，只用眼神和动作陪伴；任选一位作为主伙伴，所有功能完全相同。
- **只留在你的设备上**：无需账号，不连接网络，附完整的隐私政策、使用条款与免责声明。
