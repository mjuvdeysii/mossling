# 更新日志

## 1.0.1
稳定性、数据安全与细节修复。

- 修复计时开始 1 分钟内选择结束时间，以及导入异常日期/测量值可能引发闪退的问题。
- 加固手帐与小组件共享文件的跨进程读写同步；文件读取异常时不再覆盖已有记录，计时暂停、换边与导入失败时如实提示。
- 强化面容 ID / 密码应用锁：锁定状态下不再被计时页、弹窗或小组件快捷入口绕过。
- 修复锁屏实时活动并发同步可能出现重复卡片的问题，以及锁屏快捷计时与生长曲线性别选择的同意门控。
- 修复 CSV 表格导出与编辑页时长未扣除暂停时间、仅记录身长或头围时首页提示「还没有量过」、超 36 个月误算百分位、清除数据后未重置画风等细节问题。

## 1.0.0
首个 iOS 版本。

- 孩子摸索，大人点灯：首次打开时，Otto 的灯亮起，Moss 在灯下摸索；「关于摸索台灯」里讲述名字的故事。
- 首页：今天一起玩，每天推荐一个这个月适合的活动，第 1 步的插图一眼可见，可以「换一个」；这周另有两三个活动备选，每周自动更换。
- 活动：0–36 个月 37 站、46 个家庭活动，146 幅逐步插画；六个发展领域、专题与搜索。
- 记录（可选）：喂养、睡眠、尿布等记录与计时，可补记起止时间，暂停与换边分别计时；时间线、统计、WHO 生长曲线；锁屏实时活动与灵动岛、桌面小组件。
- 伙伴 Moss 与 Otto：不说话，用眼神和动作陪伴；可选任意一位作为主伙伴，功能相同；记录保存成功后回应一次。
- 瓶喂奶量精确到 5 毫升；统计里有亲喂时长与瓶喂奶量。
