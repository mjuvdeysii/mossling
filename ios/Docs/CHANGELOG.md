# 更新日志

## 1.1.0
适配 iOS 27 工具链、续航与导出性能优化、内容来源与细节打磨。

- **Xcode 27 与 iOS 27 适配**：升级构建环境至 Xcode 27 / iOS 27 SDK，同步适配最新系统特性与运行表现（继续兼容 iOS 26）。
- **省电与流畅度优化**：取消前台空闲时的 2 秒高频轮询，仅在计时进行中轻量监听锁屏/小组件状态；优化「给医生或 AI 看的记录」导出算法，大份手帐按日汇总速度大幅提升。
- **内容来源补齐 WHO 节奏参考**：在「关于 › 内容来源」新增 WHO 0–3 岁每日活动、睡眠、久坐与屏幕时间速查卡，方便随时翻阅。
- **质感与无障碍细节**：统一「摸索台灯的故事」翻转卡的夜灯软胶光影与翻面无障碍提示，优化伙伴选择框微边框与面容 ID 异步校验。

## 1.0.1
稳定性、数据安全与质感打磨。

- **质感与交互打磨**：统一夜灯模式下软胶卡片的暖琥珀顶边微光、按钮按压下沉景深与减动效适配；首页「换一个」新增平滑换卡过渡与轻触反馈；活动页新增蒙氏步进串珠进度条；计时页与成长册卡片统一软胶材质，成长册相纸适配夜灯暖米色；背景粒子位图缓存并离屏自动暂停省电。
- **WHO 生长曲线升级**：百分位带升级为平滑矢量曲线，新增「当前阶段 / 0–36 月」视野切换，以及曲线下方的联动测量点检视条（含较上次增幅、步进切换与直达编辑）。
- **稳定性与安全修复**：修复计时开始 1 分钟内选择结束时间，以及导入异常日期/测量值可能引发闪退的问题。
- **数据与锁屏加固**：手帐与小组件共享文件引入跨进程文件协调，读取异常不再覆盖历史记录；强化面容 ID / 密码应用锁防绕过；锁屏实时活动串行去重并补齐同意门控。
- **记录与导出修正**：CSV 导出与编辑页时长正确扣除暂停时间，兼容仅录身长/头围展示，限制百分位计算在 0–36 月龄，清除数据后同步重置画风。
