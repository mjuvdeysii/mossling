# 隐私政策

适用于 iOS 应用 芽芽月历（Mossling，Bundle ID：app.mossling）

生效日期：2026 年 10 月 22 日

## 一、概述

1. 本应用不需要账号，不收集、不上传任何个人信息，不含广告、统计分析、崩溃上报或其他第三方 SDK。
2. 用户在本应用中录入的全部信息仅保存在用户自己的设备上，开发者无法访问。
3. 本应用不访问网络。版本更新由 App Store 或 TestFlight 完成。

## 二、保存在设备上的信息

| 类别 | 内容 | 用途 |
| --- | --- | --- |
| 宝宝资料 | 出生日期；小名与性别（选填） | 计算月龄；性别仅用于选择 WHO 生长曲线 |
| 每月勾选 | 留意到的表现、做过的玩法、接种与儿保项目 | 本月进度与成长地图 |
| 本周教具架 | 用户放上架子的玩法 | 「今天」页的本周安排 |
| 手帐记录（选用） | 喂养、睡眠、尿布、辅食、洗澡、体温、用药、备注，以及正在进行的计时 | 记录、统计与桌面小组件 |
| 生长测量（选用） | 体重、身长 / 身高、头围 | 生长曲线 |
| 应用设置 | 外观、所选伙伴（Moss 或 Otto）、手帐与应用锁开关 | 显示与功能 |

以上信息保存在本应用的私有存储中，其他应用无法读取。

## 三、系统权限

| 权限 | 用途 |
| --- | --- |
| 面容 ID / 触控 ID | 仅在用户打开「应用锁」后使用，由系统完成验证，应用拿不到任何生物特征信息 |
| 实时活动 | 计时进行中时，在锁屏与灵动岛显示时长以及暂停、换边、结束按钮。应用不发送任何通知或提醒 |

本应用不申请位置、通讯录、相册、相机、麦克风、健康、通知推送等权限。

## 四、儿童个人信息

1. 本应用面向成年的父母及其他照护者，不面向儿童，也不供儿童自行操作。
2. 照护者录入的儿童信息（如出生日期、小名、性别、生长测量与照护记录）属于儿童个人信息。本应用依照《中华人民共和国个人信息保护法》《儿童个人信息网络保护规定》及适用地区（如美国《儿童在线隐私保护法》、欧盟《通用数据保护条例》）的原则处理：仅在设备本地保存和使用，不收集、不传输、不共享、不用于画像或广告。
3. 监护人可随时查看、更正、导出或删除上述信息，方式见第六、七部分。

## 五、系统备份

若设备开启了 iCloud 云备份，系统会将本应用的数据随设备备份加密保存到用户自己的 iCloud 账号，并在换机时恢复。这一过程由系统完成，不经过本应用。不需要时可在「设置 › Apple 账户 › iCloud › iCloud 云备份」中管理。

## 六、用户主动发起的操作

- **导出记录文件 / 导出表格**：文件保存在用户在系统对话框中选择的位置，由用户自行保管。
- **导入记录文件**：只读取用户在系统文件选择器中选定的、由本应用导出的那一个文件，读取后写入本机，不保留文件副本。
- **分享玩法**：只在用户点按「分享」时，把这个玩法的文字交给用户选择的应用。
- **桌面小组件与实时活动**：显示月龄、计时与最近的记录，数据来自本机，不经过任何服务器。
- **清除全部数据**：在「我的 › 记录」中，确认后删除本机上的全部记录和设置。

## 七、删除数据

可在「我的 › 记录」中清除全部数据，或删除本应用。删除后数据不可恢复。

## 八、政策的变更

本政策如有更新，将随新版本发布并在应用内「关于芽芽月历」中可查阅，生效日期同步更新。若变更涉及收集或传输个人信息，将在变更生效前在应用内显著告知并取得同意。

## 九、联系

对本政策有任何疑问、意见或投诉，可通过本应用项目主页提交：https://github.com/mjuvdeysii/mossling/issues
