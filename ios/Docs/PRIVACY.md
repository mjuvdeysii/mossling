适用于 iOS 应用 摸索台灯（Moss & Otto）

## 一、概述

1. 本应用不需要账号，不收集、不上传任何个人信息，不含广告、统计分析、崩溃上报或其他第三方 SDK。
2. 用户在本应用中录入的全部信息仅保存在用户自己的设备上，开发者无法访问。
3. 本应用不访问网络。版本更新由 App Store 完成。
4. 本应用不提供账号，因此不涉及账号注册与注销；删除个人信息的方式见第四部分第 7 条与第八部分。

## 二、保存在设备上的信息

| 类别 | 内容 | 用途 |
| --- | --- | --- |
| 宝宝资料 | 出生日期；小名与性别（选填） | 计算月龄；性别仅用于选择 WHO 生长曲线 |
| 每月勾选 | 留意到的表现、接种与儿保项目 | 本月进度 |
| 这周一起玩 | 这周推荐的几个活动、当天选择的活动 | 首页「今天一起玩」 |
| 玩过的活动 | 每次玩过的活动与时间 | 次数、成长册与导出 |
| 第一次（选用） | 孩子的第一次，名称、日期与备注 | 「第一次」页与成长册 |
| 记录（选用） | 喂养、睡眠、尿布、辅食、洗澡、体温、用药、备注，以及正在进行的计时 | 记录、统计与桌面小组件 |
| 生长测量（选用） | 体重、身长 / 身高、头围 | 生长曲线 |
| 应用设置 | 外观、所选伙伴（Moss 或 Otto）、记录与应用锁开关 | 显示与功能 |
| 小组件用的副本 | 出生日期、小名、所选伙伴、今天的活动、记录是否开启 | 桌面小组件与实时活动显示月龄和今天的活动 |

以上信息保存在本应用的私有存储中（小组件用的副本保存在仅供本应用及其小组件使用的共享容器中），其他应用无法读取，并由 iOS 数据保护加密：设备开机后首次解锁前无法读取。只有用户主动「导出」的文件，存放在「文件」App 中可见的本应用文件夹（「我的 iPhone › 摸索台灯 › 导出」）。上述信息保存到用户在应用内删除、清除全部数据、撤回同意或卸载本应用为止。

## 三、系统权限

| 权限 | 用途 |
| --- | --- |
| 面容 ID / 触控 ID | 仅在用户打开「应用锁」时验证一次，此后每次打开应用时验证；由系统完成，应用拿不到任何生物特征信息 |
| 实时活动 | 仅在用户开始计时后，在锁屏与灵动岛显示计时类型、时长、距上一顿或上一觉的时间，以及暂停、换边、结束按钮；不显示孩子的小名、体温或用药。应用不发送任何通知或提醒 |

本应用不申请位置、通讯录、相册、相机、麦克风、健康、通知推送等权限。

## 四、儿童个人信息保护规则

1. 本应用面向成年的父母和其他照护者，不面向儿童，也不供儿童自行操作。孩子的信息只能由监护人在同意本规则后填写。
2. 涉及的儿童个人信息：出生日期、小名（选填）、性别（选填）、体重、身长或身高、头围，喂养、睡眠、尿布、辅食、洗澡、体温、用药与备注等照护记录，以及「第一次」记录。其中体温、用药等属于健康信息，与不满十四周岁儿童的其他信息一样，属于敏感个人信息。本应用在首次打开时通过确认卡单独征得监护人同意后才保存这些信息。
3. 目的与方式：仅用于在本机计算月龄、显示本月内容、绘制生长曲线、汇总记录，以及显示桌面小组件和实时活动。不用于画像、推荐或广告。处理的必要性：没有出生日期无法按月龄显示内容，没有测量与照护记录无法绘制生长曲线和汇总；不填写这些信息，仍可使用全部浏览功能。对个人权益的影响：信息只在本机，开发者和任何第三方都无法获取；能使用这台设备的人可能看到，建议开启「应用锁」并设置设备锁屏密码。
4. 存储地点与期限：只保存在本设备的应用私有存储中，保存到监护人删除、清除全部数据或卸载本应用为止。开发者不设服务器，不获取这些信息，也不向任何第三方或境外提供。
5. 安全措施：使用系统提供的应用沙盒隔离存储，并由 iOS 数据保护加密；锁屏上的实时活动不显示孩子的小名、体温或用药；可开启「应用锁」，由面容 ID、触控 ID 或设备密码验证。导出的文件不加密，请妥善保管。设备丢失时，建议同时使用设备的锁屏密码。
6. 拒绝的后果：不同意本规则，仍可浏览全部玩法和月龄内容，但不能填写孩子资料和照护记录；以后需要时，可以再次选择同意。
7. 查阅、复制、更正、删除与撤回同意：在「我的」点按「编辑」查看或更正孩子资料；在「记录」中点按一条记录可修改，长按可删除；在「我的 › 数据」可导出完整备份（查阅、复制与转移），点按「清除全部数据」删除全部信息，或点按「撤回同意」在撤回的同时删除全部信息。以上操作都在本机即时完成，无需联系开发者。
8. 负责人与投诉：由开发者（{{DEVELOPER}}）负责儿童个人信息保护，联系方式为 {{CONTACT}}，投诉渠道见第十部分。
9. 本规则如有实质变化，将在应用内显著告知，并再次征得监护人同意。
10. 本应用依照《中华人民共和国个人信息保护法》《儿童个人信息网络保护规定》处理上述信息。

## 五、第三方共享、委托处理与跨境

本应用不向任何第三方共享、转让、委托处理或公开个人信息，不含第三方 SDK，不向境外提供个人信息。用户在「关于」或「内容来源」中点按外部链接时，会在系统浏览器中打开对应网站，由该网站按其自身规则处理访问信息。

## 六、系统备份

若设备开启了 iCloud 云备份，系统会将本应用的数据随设备备份加密保存到用户自己的 iCloud 账号，并在换机时恢复。这一过程由系统完成，不经过本应用。不需要时可在「设置 › Apple 账户 › iCloud › iCloud 云备份」中管理。

## 七、用户主动发起的操作

- **导出记录（给医生或 AI 看的记录、完整备份、表格）**：文件保存在「文件」App 的「我的 iPhone › 摸索台灯 › 导出」文件夹，用户点按「发送」时交给用户选择的应用，由用户自行保管。文件包含孩子的敏感个人信息；交给他人或其他应用（包括 AI 助手）后，由接收方按其规则处理。
- **导入记录文件**：只读取用户在系统文件选择器中选定的、由本应用导出的那一个文件，读取后写入本机，不保留文件副本。
- **分享玩法**：只在用户点按「分享」时，把这个玩法的文字交给用户选择的应用。
- **桌面小组件与实时活动**：显示月龄、计时与最近的记录，数据来自本机，不经过任何服务器。
- **清除全部数据**：在「我的 › 数据」页点按「清除全部数据」，确认后删除本机上的孩子资料、全部记录、设置、小组件用的副本和「导出」文件夹中的文件，并立即结束锁屏上的计时。已经发送到其他地方的文件不受影响。

## 八、删除数据

可在「我的 › 数据」页点按「清除全部数据」或「撤回同意」，或删除本应用。删除后数据不可恢复。

## 九、政策的变更

本政策如有更新，将随新版本发布并在应用内「关于摸索台灯」中可查阅，生效日期同步更新。若变更涉及收集或传输个人信息，或本政策、儿童个人信息保护规则有实质变化，将在新版本首次打开时以确认卡显著告知，并再次征得同意。
