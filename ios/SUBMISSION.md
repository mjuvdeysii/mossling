# 摸索台灯 1.0 上架提交指南

核对日期：2026-10-31。适用于 App Store Connect（以下简称 ASC）中的 iOS 1.0 版本。

## 一、总览：离上架还缺什么

应用本身已具备提交条件：
- 构建每次合入 main 后自动上传 TestFlight，最近一次为 Build 403；
- 合规对照表 25 项中 24 项通过；
- 开发者名称与联系邮箱已填入应用。

剩余缺口如下，按是否阻断提交排列。

| # | 缺口 | 是否阻断提交 | 由谁完成 |
|---|---|---|---|
| 1 | 隐私政策网址、技术支持网址（公开可访问） | 是（ASC 必填） | 负责人托管；页面内容见第四部分 |
| 2 | 6.9 英寸 App Store 截图（1320×2868），5 张 | 是 | 每次 CI 自动生成原尺寸图：GitHub › Actions › 最近一次 iOS 运行 › Artifacts › appstore-screenshots，下载后直接上传 |
| 3 | 审核联系人电话 | 是（ASC 必填） | 负责人填写 |
| 4 | 年龄分级问卷、App 隐私、价格与销售范围 | 是 | 负责人按第三部分逐项选择 |
| 5 | 中国大陆的 App 备案号 | 只阻断中国大陆店面 | 负责人（中国主体或合作方） |

| 7 | 真机实测：电量、性能，以及完整走一遍 VoiceOver | 否（建议提交前完成） | 负责人在 iPhone 上用 TestFlight 测试 |
| 8 | 外部 TestFlight 公开测试 | 否（建议先做） | 负责人在 ASC 操作 |

**建议顺序**：先开外部 TestFlight 公开链接，在中文圈收集反馈；同时准备第 1–4 项；然后在中国大陆以外的店面提交 1.0；备案完成后再加入中国大陆。

## 二、提交流程（在 ASC 中依次操作）

1. **确认协议**：ASC「业务」页确认已接受最新的《Apple 开发者计划许可协议》。免费应用不需要签付费协议，也不需要填写税务和银行信息。
2. **App 信息**：「App 信息」页填写名称、副标题、类别、内容版权、年龄分级、隐私政策网址（见第三部分 A）。
3. **价格与销售范围**：选「免费」，并选择销售地区（见第三部分 B）。
4. **App 隐私**：选择「不收集数据」，并确认隐私政策网址（见第三部分 C）。
5. **版本页（1.0）**：
   - 上传截图；
   - 填写宣传文本、描述、关键词、技术支持网址、版权；
   - 在「构建版本」中选择 Build 403 或更新的构建；
   - 填写「App 审核信息」（见第三部分 D、E）。
6. **发布方式**：选择「手动发布此版本」，审核通过后由负责人决定上线时间。
7. **提交**：点「添加以供审核」，然后提交。审核通常需要 1–2 天；如被拒，按审核回复修改后重新提交。
8. **编辑精选提名（可选）**：上线前至少两周，在 ASC「推荐提名」提交。

### B. 价格与销售范围

- **价格**：免费。
- **销售范围**：
  - 备案前不勾选「中国大陆」。
  - 可先选择中文用户较多的地区：中国香港、中国澳门、中国台湾、新加坡、马来西亚、澳大利亚、新西兰、加拿大、美国、英国。
- **欧盟各国**：ASC 要求先声明《数字服务法》（DSA）交易者身份。
  - 声明为「交易者」：须公开地址和电话。
  - 声明为「非交易者」：适用于个人非商业的免费应用。
  - 不想处理：先不选欧盟。

### C. App 隐私

- **数据收集**：选「不，我们不从此 App 中收集数据」。理由：应用不联网，不含第三方 SDK，数据只在设备上；Apple 只把传离设备的数据计为「收集」。
- 结果显示为「未收集数据」，与应用包内的隐私清单一致。

## 四、隐私政策与技术支持网址：怎么托管

ASC 只要求一个公开可打开的网址，页面内容须与应用内的隐私政策一致；技术支持页写明联系邮箱即可。可选方式：

| 方式 | 中国大陆访问 | 是否需要备案 | 说明 |
|---|---|---|---|
| 飞书文档或腾讯文档的公开链接 | 稳定 | 否 | 最省事；把隐私政策全文粘贴进去，设为「互联网上获得链接的人可阅读」 |
| GitHub Pages（本仓库已公开） | 不稳定 | 否 | 需要负责人在仓库设置中开启 Pages |
| 国内云服务器或静态托管加自有域名 | 稳定 | 是（网站备案） | 与 App 备案可一起办理 |

隐私政策全文以应用内为准（`ios/Docs/PRIVACY.md`，开发者与邮箱已填入）。需要的话，可另外生成一份可直接粘贴或上传的网页版。

## 五、外部 TestFlight 公开测试（建议先做）

1. ASC → TestFlight → 「外部测试」新建群组，例如「中文圈公测」。
2. 添加 Build 403 或更新的构建。
3. 填写「测试信息」：
   - Beta 版 App 描述：用 `ios/RELEASE.md` 第二部分第 3 节的现成文字；
   - 反馈邮箱：lbuiuiysdeyzxl@yeah.net；
   - 隐私政策网址。
4. 提交 Beta 版 App 审核，通常 1 天内完成。
5. 审核通过后开启「公开链接」，可设人数上限，例如 200。把链接发到中文圈；中国大陆用户可以安装 TestFlight 参与测试。
6. 反馈通过 TestFlight 内的截图反馈与邮箱收集，每轮汇报中统计「测试员活跃数」。

## 六、总结

- **提交前必须准备 4 项**：
  - 托管隐私政策和技术支持页，得到两个网址；
  - 6.9 英寸截图（从 CI 下载 appstore-screenshots）；
  - 审核联系电话；
  - 在 ASC 里按第三部分逐项选择。
- **中国大陆店面**：等备案号。在此之前，先上中国大陆以外的店面，并开 TestFlight 公开链接收集中文圈反馈。
- 第三部分的文字可以直接粘贴。
