00光源透明宪章 · Light-Source Charter

每一盏灯背后有什么依据、我们绝不做什么

从第一行代码到面向父母与长辈的每一张卡片，摸索台灯遵守五项公开可验证的产品契约。

契约 01 · 数据主权

0 KB 云端收集与 URL # 零服务器交接

  • 不集成任何第三方统计、广告、崩溃追踪或行为 SDK。
  • 宝宝日记、测量、纪念照片与童言录音（.m4a）均以系统文件保护存放在本机沙盒中。
  • 长辈摸索卡与传灯灯牌数据仅放在 URL # 井号后，HTTP 请求永远看不到正文。
契约 02 · 四级循证体系

每张微直觉卡均标明依据层级与边界

  • 第 1 级 · 临床指南与常模：WHO MGRS (2006)、WHO (2019/2023)、CDC (2022)、AAP、中国 NHC 规范。
  • 第 2–4 级 · 儿科专家共识、发展心理学实证与 RIE/蒙特梭利照护建议。
  • 明确拒绝缺乏大样本可复现支持的“神奇飞跃周恐吓论”，并用宽光谱替代单点合格线。
契约 03 · 双轨节律与早产守护

尊重早产矫正月龄与生病/猛涨日“减负开关”

  • 22–36 周早产宝宝 2 岁内同时以矫正月龄匹配生长曲线、玩耍站次、桌面 Widget 与发光卡。
  • 随月龄切换 4 挡照护重心：新生儿单手生存 -> 辅食探索 -> 自主表达 -> 毕业留念。
  • 开启“减负照护模式”后，探索页隐藏打卡与月龄提醒、换上安抚静养卡，台灯页突出近 24 小时体温/用药看护条与一键夜灯。
契约 04 · 买断伦理与反成瘾

永不收割焦虑，不为留存而制造红点

  • 不设连续打卡天数、不发催促推送通知、不对妈妈打分评级。
  • 00:00–04:59 自动激活 3AM 纯黑 OLED 与静谧防误触静音，绝不半夜亮白。
  • 完整本地数据可随时导出为 JSON / CSV / Markdown / 三岁成长年鉴 PDF 带走。
契约 05 · 语义与 AX3–AX5 无障碍

屏幕幕帘可用、超大字体不裁切

  • 全部卡片、观察三态按钮、滑动交接与童言声波条均提供完整 VoiceOver 语义标签与可调节手势。
  • AX3–AX5 超大字体下自动从横向并排改组为纵向自然堆叠，零横向滚动条。
  • 长辈网页卡片支持“长辈大字”开关与系统语音朗读。
临床安全边界

日常照护参谋，而非医疗诊断器械

“儿保诊室一页摘要 PDF”帮助家长在 3 分钟门急诊时清晰呈现近期喂睡、生长百分位与发热/致敏观察，但任何医学决定必须由持证儿科医生现场评估后作出。发现异常发热、呼吸急促、嗜睡或持续发育迟缓疑虑请立即就医。
