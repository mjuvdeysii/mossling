# 摸索台灯 · 品牌与 IP 正典

适用于安卓版与 iOS 版、应用内文案、商店与 GitHub 介绍。凡是描述这款应用「是什么」、Moss 与 Otto「是谁」的地方，都以本文件为准。

## 名称

中文名「摸索台灯」，英文名「Moss & Otto」（两位伙伴的名字）。安装包标识 app.mossling 保持不变。

## 1. 一句话

**孩子摸索，大人点灯。**

摸索台灯陪大人和 0–3 岁的孩子一起玩、一起长大，并把长大的样子记下来。它不是育儿课：不教大人怎么养孩子，也不给孩子打分，只为每一天留出一段一起玩的时间。

## 2. 名字的含义

| 字 | 属于谁 | 含义 | 在应用里 |
|---|---|---|---|
| 摸索 | 孩子 | 0–3 岁的孩子用手、用嘴、用眼睛摸索世界，每个月都会摸到一点新的东西 | Moss，名字取自「摸索」，头上的新芽一直在长；本周的架子上放着孩子这个月可以摸索的教具 |
| 台灯 | 大人 | 台灯不替人走路，只把桌面照亮，安静地陪在旁边 | Otto，头顶的金色灯珠就是这盏灯；夜里喂奶、哄睡时，应用变成一盏小夜灯 |

两个词合起来，就是大人和孩子在这款应用里的位置：**孩子在前面摸索，大人在旁边照亮。**

## 3. 三件事

| 应用里做什么 | 对应的页面 | 不做什么 |
|---|---|---|
| 一起玩 | 本周的架子（核心）、活动绘本：准备什么、一步步怎么玩、什么时候停下 | 不布置任务，不设打卡和连续天数 |
| 看他长大 | 0–36 个月共 37 站、成长滚轮、成长册、生长曲线 | 不比较孩子，不做发育诊断 |
| 记下来（可选） | 亲喂、瓶喂、睡眠、尿布等记录，计时显示在锁屏上 | 不上传任何数据，不需要账号 |

满 36 个月是最后一站，却不是终点：**故事仍在继续。**

## 4. 两位伙伴

### Moss（摸索）· 孩子的好奇心
- **样子**：哑光软胶质感的苔绿色圆软石，圆润饱满、没有尖角，不指向任何方向；两只眼睛；头顶一根细茎，对生的真实薄荷叶（锯齿边、叶脉），两大两小；墨色短腿。
- **性格**：小孩子的精力——活泼、好奇、停不下来，眼睛总是睁得圆圆的，什么都要先看一眼、先凑过去。
- **怎么动**：
  - 呼吸比 Otto 快（2.6 秒一次）；每 3–7 秒就张望一次，转眼很快（180 毫秒）。
  - 闲不住：时不时原地蹦一下，蹦起来时叶子竖起。
  - 眨眼很快，90 毫秒。
- **小习惯**：看见新东西先眨两下眼，再凑过去；摸到套圈、串珠或镜子会停下来，看很久。

### Otto（台灯）· 大人的陪伴
- **样子**：哑光软胶质感的深蓝高圆顶；一只大眼睛，眼皮重，眼下有一点眼袋；头顶一根弯天线，末端一颗金色灯珠。
- **性格**：大人的疲惫与慵懒——眼皮总是很重，天线微微耷拉，偶尔打一个很长的哈欠；可灯从来没灭过。他最多只笑一边嘴角。
- **怎么动**：
  - 呼吸慢（3.8 秒一次）；很久才张望一次，转眼很慢（300 毫秒）。
  - 偶尔打哈欠，1.7 秒。
  - 眨眼很慢，180 毫秒；灯珠始终微微发光。
- **小习惯**：站在 Moss 身后半步；Moss 摸到哪里，他就把灯往哪里偏一点。他从不替 Moss 去摸，也从不催。

### 两位的关系
Otto 不替 Moss 摸索，只替他照亮，正如大人陪孩子长大。两位总是一起出现。家长选的那一位站在前面，白天和夜里都一样；选谁只改变表演的节奏，不改变任何功能。

## 5. 表达规则
1. **不说话**：没有台词、气泡、字幕或口型。所有说明文字都由界面给出，用第三人称。
2. **只回应真实发生的事**：记录真正保存后，伙伴回应一次，不超过 550 毫秒；保存失败时伙伴不动，由界面如实说明。
3. **大多时候静止**：呼吸，偶尔眨眼。两位相互凑近、互相看一眼，大约每 14–24 秒一次。
4. **夜里只是安静下来**：半闭着眼，Otto 的灯珠微亮。这只是画面，不代表屏幕亮度有变化。
5. **不制造情绪压力**：不饿、不哭、不受伤，没有连续打卡；不因为家长没来、没付费而失望。
6. **照顾所有家长**：开启「减弱动态效果」时角色静止；装饰性的动画对旁白隐藏。

## 6. 世界
一张矮桌、一盏灯、一个木头架子。架子上摆着这一周的教具；地上有一条串珠小路，37 颗珠子对应 0–36 个月，最后一颗之后路还在继续。白天是阳光和草地（日光），夜里是一盏台灯（夜灯）。

## 7. 情感目标
让大人想起自己小时候趴在灯下摆弄一件小东西的那张桌子。界面安静，色彩和趣味都留给插画、教具和两位伙伴。整体要少一点说教，多一点童趣。

## 8. 制作说明
摸索台灯由创作者本人构思并主导，借助 AI（Anthropic 的 Claude）完成产品设计、插画生成与代码编写。育儿内容整理自世界卫生组织、联合国儿童基金会、国家卫生健康委员会、美国儿科学会等机构公开发布的资料，每一条都注明出处，可以在应用内「内容来源」中查看。

## 9. 视觉禁忌
- Moss 与 Otto 的造型以应用图标的设计基因为准；成品为哑光软胶三维（`tools/ip3d.py`），不用毛绒、光泽涂层或塑料反光。
- 两位都不刻意卖萌：不做大眼星星、腮红和咧嘴大笑。
- 两位同框时用同一比例尺，主伙伴明显是主角（`Duo.behind`）。
- 在插画里，两位像家人一样在场：坐在孩子身边，看着孩子正在做的事，Otto 的灯照亮它；不遮挡任何人、教具和标记，每一步都完整出现、大小一致。
- 喂奶不用红色水滴，以免看起来像血滴。
- 卡片内容放不下时换行，不用横向滑动。
