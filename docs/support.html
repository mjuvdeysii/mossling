二、高频功能指引

  • 如何切换 3D 软陶与 2D 水彩剪纸画风：在首页下拉 Otto 头顶垂下的金色灯珠，或前往「工坊」单屏控制中心一键切换。
  • 如何使用无声掌心轻拍（Silent Palm-Pat）：打开台灯页面进入「床头夜灯」，在顶部切换到「轻拍 / Pat」后将手机握于掌心，选择 60 / 54 / 48 BPM 或 5 分钟自然渐缓，亦可按实际拍打速度轻敲灯珠校准。
  • 如何导出与恢复全部本地记录：前往「工坊 › 离线数据与备份」点击「导出完整备份」，文件会写入「文件 App › 我的 iPhone › 摸索台灯 › 导出」。新机导入同样只需在此选择该 JSON 文件即可完整还原。
  • 如何清理全部本地记录：在同一「离线数据与备份」界面点击「清除全部数据」或「撤回同意」，本机沙盒及「导出」文件夹内的记录会即时删除并结束锁屏活动计时。

三、重新开启使用提示

进入「工坊」底部点按「条款与帮助」，即可找到「重新显示使用提示」按钮，在下次启动时温和重现各页面操作指引。
